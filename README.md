# Launcher

Télécharge **Asile-Install.exe** (ou le zip) et lance-le. À l’installation, il récupère **la dernière version** du lanceur depuis ce dépôt (si pas d’Internet, il installe la copie incluse). Le raccourci bureau s’appelle **Launcher**.

Une fois ouvert, le lanceur vérifie encore `version.txt`. S’il n’est pas à jour, un bandeau propose **Mettre à jour**.
