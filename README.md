# Launcher

Télécharge **Asile-Install.exe** (ou le zip) et lance-le. Il copie le lanceur inclus dans `Documents\Asile` (pas de téléchargement d’exe à l’install). Le raccourci bureau s’appelle **Launcher**.

Une fois ouvert, le lanceur vérifie encore `version.txt`. S’il n’est pas à jour, un bandeau propose **Mettre à jour**.

Version actuelle : voir `version.txt`.
