# Launcher

Télécharge **Asile-Install.exe** (ou le zip) et lance-le. Le raccourci bureau s’appelle **Launcher**.

Le lanceur vérifie `version.txt` sur ce dépôt. S’il n’est pas à jour, un bandeau propose de remplacer uniquement `AsileVocal.exe` **là où il est déjà installé**. Les comptes et options restent dans `%AppData%\AsileMinecraft`.

Version actuelle : voir `version.txt`.
