# Launcher Asile

Télécharge **Asile-Install.exe** (ou le zip) et lance-le.

Le lanceur vérifie `version.txt` sur ce dépôt. S’il n’est pas à jour, un bandeau propose de remplacer uniquement `AsileVocal.exe` **là où il est déjà installé** (raccourci bureau, dossier déplacé, etc.). Les comptes et options restent dans `%AppData%\AsileMinecraft`.

Version actuelle : voir `version.txt`.
